# Formal Methods – UPPAAL & Z Specification

A group project for BCS2213 Formal Method at Universiti Malaysia Pahang Al-Sultan Abdullah (UMPSA).

## Project Overview

This project applies formal methods to model and verify an airline self-service check-in and baggage drop kiosk system for GoldenSky Airport.

The system covers passenger verification, booking retrieval and modification, check-in confirmation, boarding pass generation, baggage tagging, and self-service baggage drop.

## Formal Methods

### UPPAAL

UPPAAL is used to model and verify the dynamic and time-dependent behaviour of the kiosk system using timed automata.

### Z Specification

Z notation is used to formally specify the system's data structures, states, constraints, and operations.

The Z specification was developed and analysed using Community Z Tools (CZT).
